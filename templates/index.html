1 Mint DOIs

Enter the journal, issue and article details. Choose a whole issue or a single article. You get a metadata deposit that registers the DOIs under {{ prefix }}.

2 Add references

Only after step one has been uploaded and processed. Paste the article's Works Cited or References list, give the article's DOI, and get a reference deposit for that DOI. The tool checks with Crossref that the DOI exists before it will build the file.

Add references

Things worth knowing

  • Reference style doesn't matter. APA, MLA or Chicago all go in as plain text, and Crossref does the matching to DOIs on its side.
  • A reference deposit replaces the DOI's existing list. Always paste the complete list.
  • Journals only. Book chapters need a different deposit type that this tool doesn't build yet.
  • Upload to the test system first if you are unsure of a file. A production deposit under a shared prefix is hard to retract.
